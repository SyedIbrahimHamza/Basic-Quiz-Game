# Basic Quiz Game

A terminal-based quiz game with multiple difficulty levels, multiple attempts per question, and score tracking.

## What it does

- Shows a main menu with options to Play Quiz or Exit
- Lets you choose a difficulty level: Easy, Medium, or Hard
- Validates your menu and difficulty choices, asking again if invalid
- Displays questions with multiple-choice options (A, B, C, D)
- Gives you multiple attempts to answer each question (5 for Easy, 3 for Medium/Hard)
- Tracks your score as you progress through the quiz
- Shows your final score at the end

## How to run it

```bash
python quiz_game.py
